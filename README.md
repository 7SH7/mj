# SLIP OUT

PDF 기획서 v0.2를 바탕으로 만든 무설치 HTML5 관성 기반 협동 탈출 게임입니다.

## 실행

`start_game.bat`을 더블 클릭하거나 `index.html`을 최신 Edge/Chrome에서 여세요. 별도 설치나 빌드는 필요 없습니다.

## 조작

| 플레이어 | 이동 | 점프 | 부스터 | 브레이크 |
|---|---|---|---|---|
| P1 | WASD | Space | Q | E |
| P2 | 방향키 | Enter | 오른쪽 Shift | `/` |
| P3 | IJKL | U | O | P |
| P4 | 숫자패드 8/4/5/6 | 숫자패드 7 | 숫자패드 9 | 숫자패드 0 |

연결된 게임패드는 플레이어 번호 순서대로 자동 인식합니다. A는 점프, B는 부스터, X는 브레이크입니다.

## 규칙

- 방향 입력은 현재 속도에 가속도를 더합니다. 고속일수록 급선회가 어렵습니다.
- 추락하거나 체력이 0이 되면 구조 코어가 남습니다. 다른 플레이어가 코어에 닿으면 즉시 부활합니다.
- 일반 모드는 전멸 시 최근 체크포인트, 극한 프리셋은 출발점에서 다시 시작합니다.
- 최종 탈출 장치 안에 잠시 머물러 탈출합니다. 전원이 함께 탈출하면 큰 보너스를 받습니다.

그래픽과 사운드는 Canvas 및 WebAudio로 런타임 생성하며 외부 에셋 의존성이 없습니다.
