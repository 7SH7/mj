# SLIP OUT

PDF 기획서 v0.2를 바탕으로 만든 무설치 HTML5 관성 기반 협동 탈출 게임입니다.

## 실행과 배포

`start_game.bat`을 더블 클릭하거나 `index.html`을 최신 Edge/Chrome에서 여세요. 별도 설치나 빌드는 필요 없습니다.

공개 배포: [https://slip-out-games.vercel.app](https://slip-out-games.vercel.app)

## 조작

| 플레이어 | 이동 | 점프 | 부스터 | 브레이크 |
|---|---|---|---|---|
| P1 | WASD | Space | 왼쪽 Shift | E |
| P2 | 방향키 | Enter | 오른쪽 Shift | `/` |
| P3 | IJKL | U | O | P |
| P4 | 숫자패드 8/4/5/6 | 숫자패드 7 | 숫자패드 9 | 숫자패드 0 |

- 메인 메뉴나 일시정지 화면의 **키 설정 및 조작 배치**에서 플레이어별 모든 키를 바꾸고 저장할 수 있습니다.
- 모바일/태블릿은 화면 왼쪽 조이스틱과 오른쪽 점프·부스터·브레이크 버튼을 사용합니다.
- 연결된 게임패드는 플레이어 번호 순서로 자동 인식합니다. A는 점프, B는 부스터, X는 브레이크입니다.

## 주요 규칙

- 체력은 20점 단위의 5개 스택으로 표시됩니다.
- 점프는 2.16초, 부스터는 5.55초의 쿨타임이 있으며 HUD와 모바일 버튼에서 남은 시간을 확인할 수 있습니다.
- 추락하거나 체력이 0이 되면 구조 코어가 남고, 동료가 닿으면 즉시 부활합니다.
- 최종 탈출 제한 시간은 일반 10초, 극한 8초입니다. 결과 화면에는 플레이어별 도착 순위와 시간이 표시됩니다.
- 일반 모드는 전멸 시 최근 체크포인트, 극한 모드는 출발점에서 다시 시작합니다.

## 코스

각 코스는 5개 섹터로 구성되며 뒤로 갈수록 장애물 종류, 배치 밀도, 속도가 증가합니다.

1. **빙하 관문** — 빙판, 회전봉, 이동 벽, 게이트, 포대, 붕괴 발판
2. **풍동 회랑** — 방향성 풍동과 탄성 범퍼 추가
3. **펄스 공장** — 주기적으로 확장되는 충격파 발생기와 강화 탄막 추가
4. **레이저 격납고** — 점멸 레이저와 교차 풍동, 추적 드론 강화
5. **코어 붕괴** — 풍동·범퍼·충격파·레이저·탄막·붕괴 발판이 모두 등장하는 최고 난도 종합 코스

그래픽과 사운드는 Canvas 및 WebAudio로 자체 생성하며 외부 에셋 의존성이 없습니다.
