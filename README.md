# SLIP OUT

PDF 기획서 v0.2를 바탕으로 만든 무설치 HTML5 관성 기반 협동 탈출 게임입니다.

## 실행과 배포

`start_game.bat`을 더블 클릭하거나 `index.html`을 최신 Edge/Chrome에서 열면 기본 게임과 로컬 기능을 실행할 수 있습니다. 공유 맵·별점·신고·운영자 기능은 서버 API가 필요하므로 공개 배포 주소에서 확인합니다.

공개 배포: [https://slip-out-games.vercel.app](https://slip-out-games.vercel.app)

## 2026-08-10 업데이트

- 첫 방문 조작 튜토리얼과 메뉴의 튜토리얼 재실행 기능을 추가했습니다.
- 온라인 방 생성 시 플레이할 1–5번 코스를 선택하도록 수정했습니다.
- 멀티 참가자 퇴장 시 안내를 표시하고 캐릭터와 HUD를 즉시 제거합니다.
- 커스텀 맵은 빈 공간에서 시작해 바닥까지 직접 배치합니다.
- 제작자 테스트 성공 후 자동 등록하지 않고 수정 복귀 또는 공유 등록을 선택합니다.
- 공유 맵을 비공개 서버 저장소에 영구 보관하고 모든 이용자가 같은 목록을 봅니다.
- 글 리뷰를 제거하고 1–5점 별점만 제공합니다.
- 사용자 삭제를 차단하고, 기기당 1회 신고와 신고 10회 이상 운영자 삭제 정책을 적용했습니다.
- 결과 화면 이후 `P1 1위 탈출`과 같은 순위 안내가 남지 않도록 정리했습니다.
- 운영자 인증, 요청 제한, 서명 쿠키와 보안 헤더를 추가했습니다.

## 조작

| 플레이어 | 이동 | 점프 | 부스터 | 브레이크 |
|---|---|---|---|---|
| P1 | WASD | Space | 왼쪽 Shift | E |
| P2 | 방향키 | Enter | 오른쪽 Shift | `/` |
| P3 | IJKL | U | O | P |
| P4 | 숫자패드 8/4/5/6 | 숫자패드 7 | 숫자패드 9 | 숫자패드 0 |

- 메인 메뉴나 일시정지 화면의 **키 설정 및 조작 배치**에서 플레이어별 모든 키를 바꾸고 저장할 수 있습니다.
- 첫 방문에는 키보드/조이스틱 이동 방식을 설명하는 실습 연습장이 열립니다. 이동·점프·부스터·브레이크를 모두 사용하면 선택한 첫 코스가 시작되며, 메뉴에서 언제든 다시 볼 수 있습니다.
- 모바일/태블릿은 화면 왼쪽 조이스틱과 오른쪽 점프·부스터·브레이크 버튼을 사용합니다.
- 연결된 게임패드는 플레이어 번호 순서로 자동 인식합니다. A는 점프, B는 부스터, X는 브레이크입니다.

## 온라인 채널

- 메인 메뉴에서 **채널 접속하기**를 누르면 현재 열린 PUBLIC 방이 표시됩니다.
- **방 만들기**에서 플레이할 1~5번 라운드, 최대 2~4명과 PUBLIC/PRIVATE을 정합니다. 생성되는 4자리 코드를 공유할 수 있습니다.
- **방 찾기**에 4자리 코드를 입력하면 PRIVATE 방에도 입장할 수 있습니다.
- 방장이 물리·충돌·점수 계산을 담당하고 참가자는 자신의 입력을 전송합니다.
- 온라인에서는 각 접속자가 P1 키 설정과 자기 기기의 모바일/게임패드 조작을 사용합니다.
- 플레이 중 참가자가 나가면 전원에게 퇴장 안내가 표시되고 해당 캐릭터와 HUD가 즉시 제거됩니다.
- P2P 연결이 제한된 학교·회사·일부 통신망에서는 방 연결이 실패할 수 있으며, 이때도 싱글 플레이는 그대로 동작합니다.

## 커스텀 맵

- 기본 코스를 전원 탈출로 3회 완주하면 CUSTOM LAB이 해금됩니다.
- 맵 에디터는 바닥이 전혀 없는 상태에서 시작합니다. 안전 바닥·빙판·초저마찰 바닥을 직접 놓은 뒤 시작점·종료 존·체크포인트와 장애물을 배치합니다.
- 제작자 테스트를 클리어해도 즉시 등록되지 않습니다. 결과 화면에서 **맵 수정으로 돌아가기** 또는 **공유 맵으로 등록하기**를 선택합니다.
- 등록 전 임시 맵은 싱글/멀티 목록이나 브라우저 저장소에 공개되지 않습니다.
- 목록의 **SINGLE PLAY** 또는 **MULTI PLAY**를 선택할 수 있습니다.
- 등록 맵은 서버 전용 Vercel Blob 비공개 저장소에 보관되고 API를 통해 공유되어, 다른 기기와 브라우저에서도 같은 목록을 봅니다.
- 검증된 커스텀 맵을 완주하면 글 없이 1~5점 별점만 남길 수 있고, 목록에서 평균과 참여 수를 확인할 수 있습니다.
- 이용자는 공유 맵을 삭제할 수 없고 기기당 한 번 신고할 수 있습니다. 신고 10회 이상인 맵은 `/admin.html`에서 운영자만 영구 삭제할 수 있습니다.
- 커스텀 멀티도 일반 채널과 동일하게 PUBLIC/PRIVATE 및 인원수를 설정합니다.

### 공유 데이터 저장 정책

- 서버 전용 비공개 Blob의 `community/state.json`에 맵, 별점 집계 원본과 신고 집계 원본을 저장합니다. 브라우저에서 Blob 파일이나 토큰에 직접 접근하지 않습니다.
- 별점과 신고의 기기 식별값은 서버에서 SHA-256 해시로 변환하며 원문을 저장하지 않습니다.
- 같은 기기는 맵별 별점을 갱신할 수 있지만 신고는 한 번만 집계됩니다.
- 동시 저장은 Blob ETag 조건부 갱신과 충돌 재시도로 보호합니다.
- 현재 보호 한도는 공유 맵 300개, 맵당 별점 2,000개, 신고 200개입니다.
- Vercel 팀은 Hobby 플랜이며, 무료 한도를 초과하면 추가 요금 대신 Blob 접근이 다음 사용 주기까지 중단됩니다. 자세한 기준은 [Vercel Blob 요금 문서](https://vercel.com/docs/vercel-blob/usage-and-pricing)를 따릅니다.

### 운영자 페이지와 보안

- 운영자 페이지는 [https://slip-out-games.vercel.app/admin.html](https://slip-out-games.vercel.app/admin.html)입니다.
- 운영자 ID, 비밀번호와 세션 서명값은 각각 `ADMIN_ID`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` Vercel Sensitive 환경변수로만 관리합니다. 실제 값은 소스와 문서에 기록하지 않습니다.
- 로그인 세션은 8시간 유효한 `HttpOnly`, `Secure`, `SameSite=Strict` 서명 쿠키를 사용합니다.
- 동일 IP의 로그인 실패는 15분 동안 5회로 제한하고, 공유 API 쓰기는 IP당 분당 30회로 제한합니다.
- 운영자 페이지에는 CSP, 프레임 차단, MIME 스니핑 차단, 리퍼러 및 권한 제한 헤더를 적용합니다.
- 운영자 API도 신고 10회 미만 맵의 삭제를 거부하므로 화면을 우회해 삭제할 수 없습니다.

### 배포 검증

- JavaScript 문법 검사와 `git diff --check`
- Edge 실제 브라우저 5개 코스·커스텀 제작 흐름 회귀 테스트
- 브라우저 2개를 이용한 방 생성·라운드 동기화·퇴장 캐릭터 제거·별점 전달 테스트
- 비공개 Blob의 등록·별점·중복 신고·10회 삭제 제한 통합 테스트
- 운영자 인증 쿠키, 요청 제한과 프로덕션 HTTPS API 테스트
- `npm audit --omit=dev` 기준 알려진 취약점 0건 확인

## 주요 규칙

- 체력은 5개 스택이며 피격 한 번마다 정확히 1칸(20 HP)씩 감소합니다.
- 점프는 2초, 부스터는 5초의 쿨타임이 있으며 HUD와 모바일 버튼에서 남은 시간을 확인할 수 있습니다.
- 체크포인트 반경은 안전지대입니다. 적이 추적·진입하지 못하고 모든 공격 피해가 무효화됩니다.
- 일반 모드에서 동료가 구조 코어에 닿으면 코어와 HUD 색이 바뀌고, 쓰러진 플레이어 본인에게 5초 카운트다운과 부활 위치 버튼이 표시됩니다.
- `I`(최신 체크포인트) 또는 `O`(쓰러진 위치)를 선택하며, 5초가 지나면 안전한 최신 체크포인트가 자동 선택됩니다.
- 극한 모드의 구조 부활은 선택 없이 항상 출발 지점입니다.
- 최종 탈출 장치 위에서 개인별로 2초를 유지하면 탈출합니다. 10초 폐쇄 카운트는 사용하지 않습니다.
- 결과 화면에는 플레이어별 도착 순위·시간·사망 횟수가 표시됩니다.
- 일반 모드는 전멸 시 최근 체크포인트, 극한 모드는 출발점에서 다시 시작합니다.

## 코스

각 코스는 5개 섹터로 구성되며 뒤로 갈수록 장애물 종류, 배치 밀도, 속도가 증가합니다.

1. **빙하 관문** — 빙판, 회전봉, 이동 벽, 게이트, 포대, 붕괴 발판
2. **풍동 회랑** — 방향성 풍동과 탄성 범퍼 추가
3. **펄스 공장** — 주기적으로 확장되는 충격파 발생기와 강화 탄막 추가
4. **레이저 격납고** — 점멸 레이저와 교차 풍동, 추적 드론 강화
5. **코어 붕괴** — 풍동·범퍼·충격파·레이저·탄막·붕괴 발판이 모두 등장하는 최고 난도 종합 코스

그래픽과 사운드는 Canvas 및 WebAudio로 자체 생성합니다. 온라인 P2P에는 [Trystero 0.25.3](https://github.com/dmotz/trystero)을 사용하며 MIT 고지 원문은 `vendor/TRYSTERO_LICENSE.txt`에 포함되어 있습니다.
